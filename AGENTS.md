# AGENTS.md

## Project goal
Build a minimal task admin app for learning Codex workflows end to end.

## Tech stack
- Next.js
- TypeScript
- Minimal dependencies
- Simple local data or SQLite only when necessary

## Working rules
- Start with a plan before large changes
- Prefer minimal, high-confidence changes
- Do not refactor unrelated code
- Explain what changed after each task
- Add or update tests for important logic when possible

## Definition of done
- App runs locally
- Core flow works end to end
- Changes are easy to review in Git
- Important behaviors are manually verifiable
